🔑 Where do I find the dashboard key?
  1. Open a terminal on the machine that runs the bot (this page only listens there).
  2. Run the command for your install: sentinel --dashboard-tokenInstalled app (.dmg, .deb, Windows Setup) python3 bot.py --dashboard-tokenRunning from source
  3. Copy the key that is printed (the first run creates it if needed) and paste it above.

The key is also saved as dashboard_token in the bot's config.json — run sentinel --paths (or python3 bot.py --paths) to see where that file lives. This is not your Discord bot token.

How the reaction gate worksMembers react with ✅ to receive that set's role. Removing the reaction removes the role. The role cannot have moderation or server-management permissions and must be below the bot's role. One server can run several rule sets — for example a "Server rules" post and a shorter "Event rules" post — each with its own channel, role and text.

Reaction role posts

Publish extra self-service role menus. Each post gets its own message and up to 20 emoji → role pairs, and every pair either gives or removes its role.

Compose the post

The bot posts this message and adds one reaction per pair. Each pair gives its role or takes it away when a member reacts.

New post
Quick add
Paste any emoji, or a custom emoji as name:id. Each pair has an action: Give role hands the role out when a member reacts — the ping-picker case — while Remove role strips it, for an opt-out emoji (e.g. "react to stop being pinged"). Insert emoji list writes the current pairs into the message so members know what each reaction does. The role must sit below the bot's role and must not carry moderation permissions — the same rules as the acceptance role. Message text is posted with mentions disabled and the bot never pings anyone. Members keep the roles they already picked if you later change or remove a pair.
